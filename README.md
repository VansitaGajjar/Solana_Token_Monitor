# 🪙 Solana_Token_Monitor

The **Solana_Token_Monitor** is a full-stack application that allows users to **monitor Solana tokens** using a React frontend and a Node.js + Express backend.  

This project demonstrates how to build a **client-server architecture** for interacting with blockchain APIs, fetching token details, and presenting them with a modern UI.

---

## 🚀 Tech Stack

### **Client (Frontend)**
- ⚛️ [React 18](https://react.dev/)  
- ⚡ [Vite](https://vitejs.dev/)  
- 🎨 [Material UI (MUI)](https://mui.com/) + Emotion (CSS-in-JS)  
- 🛠 [React Router](https://reactrouter.com/)  
- 📡 [Axios](https://axios-http.com/) for API requests  
- 🔢 [react-otp-input](https://www.npmjs.com/package/react-otp-input)  

### **Server (Backend)**
- 🟢 [Node.js](https://nodejs.org/) + [Express](https://expressjs.com/)  
- 🔐 [CORS](https://www.npmjs.com/package/cors) enabled  
- 📝 TypeScript with [ts-node](https://typestrong.org/ts-node/)

## ⚙️ Setup Instructions

### 1️⃣ Clone the Repository
```bash
git clone https://github.com/VansitaGajjar/Solana_Token_Monitor.git
cd Solana_Token_Monitor
```

### 2️⃣ Setup Backend (Server)
```bash
cd server
npm install
npm start
```
Runs on 👉 http://localhost:5000

### 3️⃣ Setup Frontend (Client)
```bash
cd client
npm install
npm run dev
```
Runs on 👉 http://localhost:5173

## 🧪 Features
- ✅ Connects frontend to backend via REST API
- ✅ Fetches and displays Solana token data
- ✅ Clean UI with MUI + Bootstrap styling
- ✅ React Router for navigation
- ✅ OTP input support (future secure actions)
